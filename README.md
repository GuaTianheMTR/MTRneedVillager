## 这个模组能做什么？

安装之后，你城市里的村民不再只是背景板：

- 🚶 **自主进站、出站**：村民会偶尔走向附近的车站闸机，入口进、出口出，完全符合现实交通逻辑；
- 🚇 **闸机自动开合**：村民碰到闸机，闸机会自动打开，通过后自动关闭——玩家过闸不受任何影响；
- 🚄 **村民会坐车！**：村民会走向停靠的列车并上车，跟着列车到下一站再下车（至少坐一站）；
- 🎫 **买票场景**：村民偶尔会走到售票机前站几秒钟，像在买票一样；
- 🏙 **零配置**：不需要任何操作，装好模组、放好车站，村民自己就会开始"通勤"。

## 安装

1. 下载 `[MTRneedVillager]1.20.1fabric_1.9.1.jar`；
2. 放入 `.minecraft/mods` 文件夹；
3. 同时安装：**Fabric API**（1.20.1 任意版本）和 **MTR 4.0.5+（4.1.x 以下）**；
4. 启动游戏，进入世界即可生效——**无需任何其它配置**；
5. 进服后聊天栏会弹出绿色消息 `[MTRneedVillager] MTRNV启动成功！`，看到它就说明模组已启动。

## 如何体验

1. 用 MTR 建造一个带**入口闸机**和**出口闸机**的车站（闸机朝向相反摆放）；
2. 在车站附近放几只村民，再放几台售票机；
3. 等待几分钟——村民就会开始"通勤"：买票、进站、等车、上车、到站下车、出站。

**效果提示**：夜晚 + 灯光 + 站台列车，观察村民乘车和过闸的瞬间最有电影感 🎬

---

## 常见问题

- 村民只在**入口侧**过闸，不会反向强穿闸机；
- 村民上车、下车全程自主，若车站地形复杂，村民偶尔会绕路或放弃（过一会儿会重新尝试）；
- 村民下车会回到站台上，不会卡在屏蔽门里；
- 本模组为 **beta** 版本，可能存在未知问题，请提前备份存档。
